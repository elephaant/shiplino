# Virtual office assets

The office in the web app (`/office/`) is drawn on a canvas from small pixel sprites written as code in [`web/apps/local/src/components/office/sprites.ts`](../../web/apps/local/src/components/office/sprites.ts). They were drawn by hand for Shiplino, are not based on any game or art pack, and are covered by the repository's Apache-2.0 license like the rest of the code. There are no image files yet.

**Licensing rule for future asset files:** every asset pack goes in its own folder here with a `LICENSE` file that states its license and author. Only add art that is ours (Apache-2.0) or under a compatible open license (CC0, CC BY). No unknown-license or "free for personal use" assets, and nothing copied from games or look-alikes of them.
