# plugins

- `claude-code/`: optional Claude Code plugin package (the installer uses user settings instead, so this is an alternative).
- `opencode/`: OpenCode plugin that forwards events to Shiplino.
- `vscode/`: VS Code / Cursor / Windsurf extension (status bar + board panel).

All plugins must follow the zero-token rules in [docs/how-it-works.md](../docs/how-it-works.md).
